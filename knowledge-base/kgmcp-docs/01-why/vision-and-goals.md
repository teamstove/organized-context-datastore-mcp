# ビジョンと目標

## ビジョン
LLM が「プロジェクト知識」に自然言語でアクセスし、一貫性のあるコンテキストを維持できる世界。

## 達成目標

### 1. Token効率の最大化
LLMのコンテキストウィンドウは有限。必要な情報のみを精粋化して提供。

### 2. 構造化された知識管理
階層的なコンテキスト構造で、知識の関係性を明確に。

### 3. 版管理とトレーサビリティ
Git/PostgreSQLによる変更履歴管理で、知識の進化を追跡。

### 4. 柔軟なストレージ選択
ファイルベース（Git）とデータベース（PostgreSQL）を用途に応じて選択。
