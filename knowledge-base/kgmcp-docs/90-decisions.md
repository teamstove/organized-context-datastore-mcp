# Decisions - アーキテクチャ決定記録

重要な設計決定を ADR (Architecture Decision Record) 形式で記録します。

## ADR 一覧
- [ADR-001](./adr-001-tree-text-format) - tree-text フォーマットの導入 (accepted)
- [ADR-002](./adr-002-remove-legacy-write-tools) - 旧書き込みツールの削除 (accepted)


## ADR フォーマット
各 ADR は以下の構造を持ちます：
- **Status**: proposed / accepted / deprecated / superseded
- **Context**: 決定が必要になった背景
- **Decision**: 何を決定したか
- **Consequences**: 決定による影響
